# OpenLatch Phase 1 基准基线

生成：2026-08-29　来源：`BenchmarkMain`（design D5 手写 harness）

## 环境

| 项 | 值 |
|---|---|
| OS | Linux 7.0.0-30-generic |
| CPU | 8 核 |
| JDK | 25.0.3 |
| 服务器 | 进程内内嵌，默认配置（lease 30s / tick 500ms / 临时端口） |
| 客户端 | 单实例（连接多路复用），1 EventLoop 线程 |
| 采样 | 热身 4s；3 批 × 5s，吞吐取批中位；延迟为蓄水池样本（每线程 32768），分位数按批计算后取中位 |

## 指标

| 场景 | ops/s（中位） | 往返/授予延迟 P50 (ms) | P99 (ms) |
|---|---|---|---|
| 无竞争 tryLock 往返 | 11272 | 0.04 | 0.10 |
| 16 线程竞争 lock() | 11424 | 1.22 | 2.02 |
| 64 线程竞争 lock() | 11257 | 5.30 | 8.68 |

> 竞争场景延迟列为**授予延迟**（发起到授予，含排队）。本基线仅作防退化参考，不作发布门槛（详设 §10.5）。
