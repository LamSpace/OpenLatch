## MODIFIED Requirements

### Requirement: 五页面只读呈现

控制台 SHALL 提供服务端渲染页面（无前端构建链），内容与 §4.3 对齐且全程只读（MUST NOT 提供任何强制解锁、踢会话等写操作入口）：

- **概览**：各节点 SUMMARY 数字（持有/等待/会话/角色/运行时长/版本，含 Latch、ATOMIC 与 BARRIER 单列条目数）+ 核心指标趋势曲线；
- **锁列表**：分页浏览、前缀过滤输入、点击进详情；多节点时标注数据来源节点并合并呈现；ATOMIC 行呈现家族、形态与当前值；BARRIER 行呈现 parties、当前世代与到场数；
- **锁详情**：持有者（会话/线程/计数或许可）、等待队列位次与会话、剩余租约倒计时；ATOMIC 详情呈现形态、定型初值、当前值与版本戳（无持有者/等待者区段以"无此语义"呈现而非空表）；BARRIER 详情呈现 parties、当前世代号、当前到场数、动作挂账标记与最近完结世代的了结形态（无持有者区段同样以"无此语义"呈现；等待队列即世代内到场在队者）；follower 来源的"等待队列仅 Leader 可见"如实标注；
- **会话列表**：各节点接入会话——id、接入节点、建连时间、持锁数、等待数；
- **节点视图**：集群成员表与 Leader 标识（经 `CLUSTER_VIEW`），单机部署报单机。

#### Scenario: 预置状态页面断言

- **WHEN** 服务端预置锁/信号量/Latch/原子变量/循环屏障/等待者后抓取各页面 HTML
- **THEN** 概览数字、锁列表行、详情持有者与等待位次、ATOMIC 值与版本戳、BARRIER 世代与到场数与会话列表条目逐项可见且与服务端状态一致

#### Scenario: 只读边界

- **WHEN** 检视全部页面渲染结果
- **THEN** 不存在任何触发写操作（解锁/踢会话/变更配置）的表单或链接
