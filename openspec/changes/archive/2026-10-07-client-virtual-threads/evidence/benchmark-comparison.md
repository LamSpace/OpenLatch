# 基准前后对比（任务 1.3 / 5.2）

- 环境：同机同参（Linux 7.0.0-38，8 核，JDK 25.0.3，进程内服务端默认配置），各 3 批 × 5s 取批中位
- 基线：`benchmark-baseline-before.md`（改动前 HEAD，client 走仓库 jar）
- 复跑：`benchmark-after.md`（改动后，client 重新 install 入本地仓库后同形单模块复跑）
- 注：`-am` 形态下 `exec:java` 落根聚合 pom 致 ClassNotFound（既有判例变体），故复跑走 install + `-pl openlatch-examples` 单模块形态，测量口径与基线一致

## 结果

| 相 | 吞吐 前→后 | p99 前→后 | 判读 |
|---|---|---|---|
| 无竞争 tryLock | 10896 → 11163 | 0.10 → 0.10 | 噪声带内 |
| 16/64 线程竞争 lock() | 11138/10297 → 11352/10731 | 2.25/11.65 → 2.27/9.57 | 噪声带内（64 线程 p99 反降） |
| 原子族（add/get/CAS/引用） | 各 ±10% 双向 | 0.10–0.13 区间 | 噪声带内 |
| 队列族（交接/扇出/drain/延时尾延） | 19735→21624、28877→30310、38029→40653 | 0.21→0.19、0.89→0.89、2.45→2.40 | 不升 |
| topic 零订阅发布基线 | 19937 → 21270 | 0.11 → 0.10 | 不升 |
| topic 1×8 扇出交付 | 8492 → 7692（-9.4%） | 0.91 → 0.92（+1%） | 该相其余量级同幅波动（他相 -10%～+18%），p99 无实质劣化 |
| 条件/phaser/timer 各相 | ±8% 内双向 | 同带 | 噪声带内 |
