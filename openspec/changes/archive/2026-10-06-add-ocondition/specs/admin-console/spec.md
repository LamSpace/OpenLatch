# Spec Delta

## MODIFIED Requirements

### Requirement: 五页面只读呈现

控制台 SHALL 提供服务端渲染页面（无前端构建链），内容与 §4.3 对齐且全程只读（MUST NOT 提供任何强制解锁、踢会话等写操作入口）：

- **概览**：各节点 SUMMARY 数字（持有/等待/会话/角色/运行时长/版本，含 Latch、ATOMIC、BARRIER、QUEUE 与 TOPIC 单列条目数；等待数字口径含条件等待者——v9 与指标能力口径互注）+ 核心指标趋势曲线；
- **锁列表**：分页浏览、前缀过滤输入、点击进详情；多节点时标注数据来源节点并合并呈现；ATOMIC 行呈现家族、形态与当前值——标量形态呈现数值，有值引用形态（`reference`）呈现载荷字节大小与截断预览；BARRIER 行呈现 parties、当前世代与到场数；QUEUE 行呈现形态（`queue`/`delay_queue`）、容量与当前深度、首元素字节大小与截断预览（延时形态并注首元素到期时刻）；TOPIC 行（Leader 来源）呈现订阅数（family=topic 行由管理面订阅登记键渲染，Follower 来源如实无该行）；**LOCK 行的条件等待数（`condition_waiters`）随行呈现（Leader 来源非零如实、Follower 来源如实零）**；
- **锁详情**：持有者（会话/线程/计数或许可）、等待队列位次与会话、剩余租约倒计时；**条件等待区段（与等待队列区段并列：条件名、会话、请求 id、线程、已等待时长，按集合到达序呈现；已搬运入队者只在等待队列区段计位次、不在条件区段重复出现；无持有者而存在条件等待者时如实呈现"持有已随 await 释放"的形态注记，不以空壳掩盖）**；ATOMIC 详情呈现形态、定型初值、当前值与版本戳（有值引用形态的初值/当前值以字节大小+截断预览呈现，null 态如实呈现为 null 而非空；无持有者/等待者区段以"无此语义"呈现而非空表）；BARRIER 详情呈现 parties、当前世代号、当前到场数、动作挂账标记与最近完结世代的了结形态（无持有者区段同样以"无此语义"呈现；等待队列即世代内到场在队者）；QUEUE 详情呈现定型容量、当前深度、总驻留字节、首元素大小与截断预览、首元素到期时刻（DELAY 形态）与双轨挂起等待者（等容量/等元素分列位次；无持有者区段以"无此语义"呈现；全量元素列表不呈现）；TOPIC 详情呈现订阅数与订阅者列表（会话 id、订阅 id、订阅时刻；无持有者/等待区段以"无此语义"呈现；已交付消息内容不呈现）；follower 来源的"等待队列仅 Leader 可见"如实标注（**条件等待明细同口径随行标注**），topic 键的 follower 视角未命中如实呈现（不渲染空壳详情）。

#### Scenario: 预置状态页面断言

- **WHEN** 服务端预置锁/信号量/Latch/标量原子变量/有值引用（含 null、恰限大载荷）/循环屏障/队列（含满容量恰限元素与未到期延时元素、双轨挂起等待者）/topic 键（含多会话订阅）/**两条件多等待者的互斥锁（含一名已搬运入队项）**后抓取各页面 HTML
- **THEN** 概览数字（含 `queue_entries` 与 `topic_entries`、等待合计含条件等待者）、锁列表行、详情持有者与等待位次、ATOMIC 值与版本戳、引用条目的大小与截断预览、BARRIER 世代与到场数、队列行的容量/深度/首元素预览与到期标注、双轨等待区段、TOPIC 行的订阅数与详情订阅者列表、**详情条件等待区段五字段与互斥计数（搬运项不重复出现）、LOCK 行条件等待数**、会话列表条目逐项可见且与服务端状态一致；恰限大载荷/大元素的预览为截断呈现（页面不含全量载荷、全量元素列表或任何消息内容）

#### Scenario: 只读边界

- **WHEN** 检视全部页面渲染结果
- **THEN** 不存在任何触发写操作（解锁/踢会话/退订/**signal 或代为唤醒**/变更配置）的表单或链接
